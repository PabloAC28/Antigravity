# Nexus Hardware 🚀

Nexus Hardware es una plataforma de catálogo premium diseñada para la visualización y gestión de componentes de hardware de alto rendimiento. Ofrece una interfaz moderna con estética *glassmorphism* y un sistema de administración robusto para el control de inventario.

## 🛠️ Tecnologías Utilizadas

- **Backend:** PHP 8.x
- **Base de Datos:** SQLite 3 (integración vía PDO)
- **Frontend:** 
  - HTML5 Semántico
  - Vanilla CSS3 (diseño premium, efectos de brillo y desenfoque)
  - Google Fonts (Inter & Outfit)

## ✨ Características Principales

- **Catálogo Dinámico:** Visualización de componentes con indicadores de stock en tiempo real.
- **Detalle de Producto:** Información extendida sobre cada componente.
- **Acceso Administrativo:** Sistema de login seguro para gestionar el inventario.
- **Gestión CRUD:** Los administradores pueden añadir, editar y eliminar componentes.
- **Responsive Design:** Optimizado para diferentes tamaños de pantalla.

## 🚀 Instalación y Configuración

Sigue estos pasos para configurar el proyecto en tu entorno local:

1. **Clona el repositorio** o descarga los archivos en tu servidor web local (XAMPP, Laragon, etc.).
2. **Configura la Base de Datos:**
   - Localiza el archivo `config.example.php` en la raíz del proyecto.
   - Renómbralo a `config.php`.
   - El sistema utilizará automáticamente una base de datos SQLite (`database.sqlite`).
3. **Inicialización:**
   - Al acceder por primera vez a la aplicación a través del navegador, la base de datos se creará y se poblará con datos de prueba automáticamente.
